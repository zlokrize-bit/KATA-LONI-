# KATA LONI — بانل قياس البينج للألعاب

## شنو هذا المشروع بالضبط؟
تطبيق يعرض **بانل عائم (Overlay)** فوق أي لعبة تختارها، يوريك البينج (زمن الاستجابة) للسيرفر بشكل مباشر، ويظهر تلقائيًا بس وقت ما تفتح لعبة من قائمتك.

⚠️ **مهم توضيحه:** هذا التطبيق **لا يقوم بعملية تشفير/تمرير حركة البيانات (VPN Tunnel) بنفسه** — هذي وظيفة v2RayTun اللي ثبتناه سابقًا ووصلناه بسكربت السيرفر. هذا التطبيق يشتغل **جنب** v2RayTun، ويضيف له طبقة "البانل + قياس البينج + اختيار الألعاب" اللي طلبتها.

## طريقة الفتح والبناء (5 دقائق)

### 1. حمّل Android Studio
من الموقع الرسمي: https://developer.android.com/studio (مجاني، تثبيت عادي)

### 2. افتح المشروع
- افتح Android Studio
- اختر **Open**
- اختر مجلد `KataLoniPanel` كامل (اللي جوا الملف المضغوط اللي عطيتك)
- انتظر أول Sync (يحمّل المكتبات تلقائيًا — يحتاج إنترنت على جهازك، يستغرق دقايق حسب سرعة النت)

### 3. جرّبه مباشرة (اختياري)
وصّل جوالك بالكيبل، فعّل "خيارات المطور + USB Debugging"، واضغط زر ▶️ الأخضر فوق — يثبت التطبيق على جوالك مباشرة للتجربة.

### 4. ابنِ ملف APK النهائي
```
Build → Build Bundle(s) / APK(s) → Build APK(s)
```
بعد الانتهاء، يطلع لك رابط "locate" يوديك لمكان ملف الـ APK. انسخه لجوالك وثبّته.

## طريقة الاستخدام بعد التثبيت
1. افتح **KATA LONI**
2. اكتب IP السيرفر تبعك (نفس اللي طلع من سكربت السيرفر)
3. من القائمة تحت، حط ✅ على الألعاب اللي تبيها
4. اضغط الأزرار الثلاثة بالترتيب:
   - اسمح بالعرض فوق التطبيقات
   - اسمح بالوصول لبيانات الاستخدام
   - تشغيل البانل
5. افتح أي لعبة من اللي حطيت عليها ✅ → البانل يطلع تلقائيًا فوقها يوريك البينج

## هيكل المشروع
```
KataLoniPanel/
├── app/src/main/java/com/katalonI/panel/
│   ├── MainActivity.kt        ← الشاشة الرئيسية (اختيار الألعاب + الصلاحيات)
│   ├── PingOverlayService.kt  ← الخدمة اللي تعرض البانل وتقيس البينج
│   ├── GameAdapter.kt         ← قائمة الألعاب (RecyclerView)
│   ├── Game.kt                ← نموذج بيانات اللعبة
│   └── Prefs.kt               ← حفظ الإعدادات محليًا على الجهاز
├── app/src/main/res/          ← الواجهات والألوان والأيقونات
└── app/src/main/AndroidManifest.xml
```

## تعديلات مستقبلية ممكنة (لو تبي تطور بنفسك لاحقًا)
- تغيير طريقة قياس البينج (الحين تستخدم TCP connect timing، تقدر تبدلها لـ ICMP لو تبي دقة أعلى)
- إضافة رسم بياني لتاريخ البينج بدل رقم واحد
- إضافة إحصائيات استهلاك البيانات
